# 💳 Gestionnaire d'Abonnements

Un outil simple, moderne et intuitif développé en Python et Streamlit pour suivre, gérer et optimiser vos abonnements et dépenses récurrentes.

🔗 **Accéder à l'application en ligne :** [Cliquez ici pour tester le site](https://gestionnaire-abonnement-tnz6qkcfyeudwdbwghlka5.streamlit.app/)

---

## ✨ Fonctionnalités
- Suivi de vos abonnements (services de streaming, logiciels, abonnements mobiles, etc.).
- Visualisation claire des dépenses mensuelles ou annuelles.
- Interface utilisateur fluide et interactive grâce à Streamlit.

## 🛠️ Technologies utilisées
- **Python** (Langage principal)
- **Streamlit** (Interface graphique et hébergement)
- **GitHub** (Gestion de code source)
